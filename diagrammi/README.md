# Diagrammi UML

I diagrammi del progetto sono scritti in [PlantUML](https://plantuml.com/) e organizzati per tipo:

| Cartella | Contenuto |
|---|---|
| `casi-uso/` | Diagrammi dei casi d'uso |
| `classi/` | Diagrammi delle classi |
| `sequenza/` | Diagrammi di sequenza delle interazioni principali |

Per ogni diagramma sono presenti tre file con lo stesso nome:

- `nome.puml` — sorgente PlantUML, da modificare;
- `nome.png` — immagine generata dal sorgente;
- `nome.md` — descrizione e commento del diagramma (elementi rappresentati e scelte effettuate).
