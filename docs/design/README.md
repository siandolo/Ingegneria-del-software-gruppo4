# Design

Questa cartella contiene il documento di progettazione del sistema:

- `design.md` — sorgente del documento, aggiornato tramite commit;
- `Design_v1.pdf`, `Design_v2.pdf`, … — versioni consegnate.

Una versione consegnata non viene mai sovrascritta: se il documento cambia dopo una consegna, si aggiunge una nuova versione con il numero successivo e la precedente resta disponibile.

I diagrammi delle classi e di sequenza si trovano in [`diagrammi`](../../diagrammi).
