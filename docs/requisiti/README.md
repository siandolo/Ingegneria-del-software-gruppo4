# Requisiti

Questa cartella contiene il documento di specifica dei requisiti dell'applicazione:

- `requisiti.md` — sorgente del documento, aggiornato tramite commit;
- `Requisiti_v1.pdf`, `Requisiti_v2.pdf`, … — versioni consegnate.

Una versione consegnata non viene mai sovrascritta: se il documento cambia dopo una consegna, si aggiunge una nuova versione con il numero successivo e la precedente resta disponibile.

I diagrammi dei casi d'uso si trovano in [`diagrammi/casi-uso`](../../diagrammi/casi-uso).
